# Band 개발팀 설정

Band Desktop에서 운영할 개발팀의 역할, 공통 규칙, 작업 양식과 현재 설정 기록입니다.

- [에이전트 구성 및 적용 방법](Agents/README.md)
- [공통 운영 규칙](Agents/common.md)
- [현재 런타임 설정](Agents/runtime-settings.md)

현재 연습팀은 Coordinator, Code Author, Code Reviewer입니다. 6개 역할의 지침은 설계안이며, 파일을 저장하는 것만으로 Band 설정이 바뀌지는 않습니다.

이 저장소는 공장 설정을 관리합니다. 대회 제출용 결과 저장소와 공식 과제 자료는 별도로 관리합니다. 로컬의 `band-work/`, `sf-buildathon-2026/`와 원본 room 로그는 `.gitignore`로 제외했습니다.

`.gitkeep`은 빈 디렉터리를 Git에 남기기 위한 관례입니다. 업로드 제외는 `.gitignore`로 지정합니다. `Agents/`에는 실제 파일이 있으므로 `.gitkeep`이 필요하지 않습니다.
